REQUISITOS
----------

Amstrad CPC 6128 o emulador compatible. 128K de memoria.

ARRANQUE DESDE DSK
------------------

1. Monta game/banterhouse.dsk en la unidad A.
2. Escribe: run"loader
3. Pulsa Intro.

Espacio         Acción
Esc             Pausa
